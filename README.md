# Student Result Card

## About the Project
A simple Student Result Card created using HTML5 and CSS3. It displays student information, profile picture, subject-wise marks, and total score in a clean card layout.

## Technologies Used
- HTML5
- CSS3

## Features
- Student profile section
- Subject-wise marks display
- Total score display
- Gradient background
- Card hover effect
- Profile image styling
- Box shadow and rounded corners

## Project Structure
Student-Result-Card/
├── index.html
├── style.css
├── download.jpg

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Disclaimer
This project is created for educational purposes only. All student details and marks are sample data and do not represent an official academic result.
